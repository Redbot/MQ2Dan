# /dggaexecute

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/dggaexecute <command>
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
Executes a command on all clients in your current in-game group (including own). Short version: /dgga
<!--cmd-desc-end-->
